## 🆘 TROUBLESHOOTING DURING DEPLOYMENT

### Issue: Website doesn't load
**Solution:**
1. Check domain DNS propagation (nslookup malenglegacy.co.za)
2. Verify files uploaded to correct directory
3. Check file permissions (644 for files, 755 for folders)
4. Restart web server on HostAfrica

### Issue: Styles not loading (CSS missing)
**Solution:**
1. Check `.next/static/css/` folder exists
2. Verify CSS files uploaded
3. Clear browser cache (Ctrl+Shift+Del)
4. Check browser console for 404 errors

### Issue: Animations not working
**Solution:**
1. Check Framer Motion is in node_modules
2. Verify JavaScript files uploaded
3. Check browser console for JS errors
4. Test on different browser

### Issue: Google Analytics not tracking
**Solution:**
1. Check NEXT_PUBLIC_GA_ID in .env.local
2. Verify GA property is created
3. Check browser console for GA errors
4. Go to GA4 > Admin > Property Settings > Data Streams > Web > Verify
5. Allow 24 hours for first data to appear

### Issue: Images not loading
**Solution:**
1. Check image files exist in `/public` folder
2. Verify image paths are correct
3. Check image file formats (JPG, PNG, WebP)
4. Optimize large images
