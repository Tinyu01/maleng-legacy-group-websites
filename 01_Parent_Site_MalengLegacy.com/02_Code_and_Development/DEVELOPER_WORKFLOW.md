# Developer Workflow (Parent + Subsidiary Sync)

This guide is the standard workflow for developers working on the Maleng Legacy websites.

## Architecture (Important)

There are two code locations for subsidiary pages:

1. **Standalone source of truth (edit here):**
   - `02_Subsidiary_Sites_Template/[Subsidiary]/02_Code_and_Development/project/pages/index.js`
2. **Parent integrated routes (auto-generated by sync):**
   - `01_Parent_Site_MalengLegacy.com/02_Code_and_Development/project/pages/subsidiaries/*.js`

When using parent-site development (`/subsidiaries/...` routes), parent files are synced from standalone files.

---

## Daily Startup (2 terminals)

From:
`01_Parent_Site_MalengLegacy.com/02_Code_and_Development/project`

### Terminal 1: Parent website
```bash
npm run dev
```

### Terminal 2: Auto-sync watcher
```bash
npm run sync:subsidiaries:watch
```

Now any save in standalone subsidiary `pages/index.js` auto-syncs to parent `pages/subsidiaries/*.js`.

---

## One-Time Manual Sync

If needed (or before build/deploy):

```bash
npm run sync:subsidiaries
```

---

## Adding a New Subsidiary

1. Create/copy standalone subsidiary folder in `02_Subsidiary_Sites_Template`.
2. Create the page at `.../project/pages/index.js`.
3. Update mapping in:
   - `project/scripts/sync-subsidiaries.js`
   - Add folder → route filename entry in `SUBSIDIARY_MAP`.
4. Run:
   - `npm run sync:subsidiaries`
5. Verify parent route works at `/subsidiaries/[name]`.

---

## Rules for Developers

- Do **not** manually edit parent `pages/subsidiaries/*.js` when using this workflow.
- Edit standalone files, then let sync update parent routes.
- Keep import paths in standalone files as `../components/...`.
- Sync script handles conversion for parent route files.

---

## Troubleshooting

### Parent does not reflect latest subsidiary change
1. Confirm watcher is running:
   - `npm run sync:subsidiaries:watch`
2. Run manual sync:
   - `npm run sync:subsidiaries`
3. Hard refresh browser (Ctrl+F5).

### Port 3000 already in use
```bash
npm run dev -- -p 3001
```

### Watcher running multiple times
Stop extra terminals/processes and keep one watcher terminal only.
